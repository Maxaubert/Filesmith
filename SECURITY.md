# Security policy

## Supported versions

Only the latest release gets security fixes. Please update to the latest
release before you report a problem.

## Report a vulnerability

Use GitHub private vulnerability reporting. Open the repository's Security
tab and choose "Report a vulnerability".

Please do not open a public issue for a security problem.

## What to include

- The Filesmith version and your Windows version.
- What you did, and what happened.
- Steps to reproduce, or a sample file that shows the problem.
- What you think the impact is.

## What to expect

Filesmith has one maintainer. I will read your report and reply on a
best-effort basis. I cannot promise a fixed response time. When a fix is
released, I will say so in the release notes.
