Filesmith console

Four concepts for the limited in-app console: it runs filesmith commands only, typed without the prefix; anything else gets one calm line pointing to Open in terminal. Console jobs never join the queue or Completed; each finished run offers Show in File Explorer. Each screenshot opens the live mockup in that state: press Ctrl+` or click Console, then type (try convert *.heic --to webp, del *.*, Tab, Up/Down, Ctrl+C while running).

A VS Code style panel under the files view; the inspector keeps full height. Console button in the toolbar, Stop sits red in the panel header while a run is going.
