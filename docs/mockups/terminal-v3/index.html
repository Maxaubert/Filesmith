Filesmith, terminal round 3

20 directions with icons and more substance. Click a card to open the full mockup.

01Wind Classic

Filesmith as a sibling of Wind Settings: same rail, same header band, same cards. The queue sits in the middle and the options on the right, with nothing left over.
02Wind Stacked Rows

Wind's single-column settings rhythm: a queue card, then an options card made of real Wind rows, and the floating Save pill that becomes Convert.
03Wind Tiled Nav

Wind with a little more presence in the rail: every verb icon lives in its own small tile, so the nav reads as a set of tools, not a list of words.
04Wind Grouped Rail

Wind Settings structure, with the rail grouped like Wind's bottom group: Image, AI and More sections make 7 verbs feel organised, not long.
05Wind Command Header

Wind's layout, but the header band does the heavy lifting: the title, the file count, Add files and the Convert button all live in one confident band, which leaves the body for the queue and a slim options card.
06Linear Inspector

Linear's calm list plus a single quiet inspector: the queue is a borderless list with hairlines, and the options live in a full-height right pane separated by one line.
07Raycast Panel

The whole app as one Raycast-like floating panel on black: verb tabs along the top, a list in the middle, and an action bar at the bottom.
08Zed Activity Bar

An editor-like activity bar: a narrow column of stacked icon-plus-label buttons, which frees width for a wide queue and a generous options column.
09Top Icon Tabs

No sidebar at all: the verbs become a row of icon-and-label tabs under the titlebar, so the content gets the full 1440px width.
10Segmented Switcher

The verbs live in one segmented control, like a mode switch on a pro camera: a single object that says this app does seven things.
11Bottom Dock

The verbs sit in a quiet dock at the bottom, like a tool tray, so the top of the window belongs entirely to the job at hand.
12Thumbnail Grid

Files as visual cards, not lines: a 3x2 grid of thumbnails where each card shows its own status, which feels more like a media tool.
13Quiet Table

The queue as a proper table with four light column headers, for people who like to scan by column: name, size, result, status.
14Prompt Title

Round 2's prompt-caret idea with real substance: the page title reads like a command, but the screen around it is a complete, carded app.
15Glyph Gutter

Status first: every queue row starts with a status glyph in its own gutter, so the column of checks, a ring and a triangle tells the story before you read a name.
16Drop Frame

The queue lives inside a visible drop frame: the dashed boundary says 'drop here' all the time, so the empty-state idea becomes the structure.
17Preview Column

A media tool should show the picture: the right column opens with a greyscale preview of the selected file and its expected result, then the options, so you see what you are about to make.
18Ruled Sheet

Typography-led with real weight: one 2px white rule under the header carries the structure, and the queue and options sit on a single ruled sheet with clear sections, not floating cards.
19Verb Sentence

The header is a sentence you can edit: 'Convert 6 files to WebP, Balanced, next to source', where each grey word is a select that sets that option, so the sentence is the options panel.
20Toolbar Strip

All options in one toolbar strip above the queue, like an image editor's options bar, so the queue gets the full width and plenty of room.
