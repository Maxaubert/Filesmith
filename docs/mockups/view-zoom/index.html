Filesmith view zoom

Four concepts for resizing the files view. Each screenshot opens the live mockup at that size: hold Ctrl and scroll inside the files view (or Ctrl+= / Ctrl+-, Ctrl+0 resets).

01 Steps with toast

Five fixed steps from compact list to large grid; a brief toast names the size, a view dropdown at the toolbar end sets it without a wheel.

#size=0 compact list#size=1 list#size=2 large list#size=3 grid S#size=4 grid Lview menu

02 Slider in toolbar

A list-to-grid slider with a size label sits in the files toolbar and always shows the current size; Ctrl+wheel snaps it between six stops.

#size=0 compact list#size=1 list#size=2 large list#size=3 small grid#size=4 grid#size=5 large grid

03 List/Grid toggle plus zoom

A List/Grid segmented toggle picks the mode; Ctrl+wheel changes density inside it (3 list sizes, 3 grid sizes) with a -/+ readout.

#size=0 list 1/3#size=1 list 2/3#size=2 list 3/3#size=3 grid 1/3#size=4 grid 2/3#size=5 grid 3/3

04 Explorer style

Sizes named like Windows File Explorer (Details, Tiles, Medium, Large, Extra large icons) in a View menu with Ctrl+Shift+1..5.

#size=0 details#size=1 tiles#size=2 medium icons#size=3 large icons#size=4 extra large iconsview menu
