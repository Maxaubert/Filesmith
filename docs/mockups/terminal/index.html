filesmith / terminal redesign / 20 mockups

dark only. click a card to open the mockup.

01Wind Native

The safe bet: Filesmith rebuilt on Wind's exact settings DNA, so the two apps feel like siblings.
02Wind Dense Inspector

Wind's tokens tightened into a pro-tool table with a fixed right inspector, for people who want to see 40 rows at once.
03Tmux Panes

The window is a tmux session: three hard-split panes and a green status line, with real GUI controls inside each pane.
04Command First

No sidebar at all: a big command bar owns the top of the window and every verb is one keystroke away, Raycast for files.
05TUI Function Keys

An htop or Midnight Commander homage drawn with box characters, with a F-key bar along the bottom for every verb.
06REPL Log

The app is a scrolling session log with a prompt at the bottom; every drop, option and result is a line you can read back.
07Swiss Rules

Brutalist Swiss: heavy white rules, a condensed display face and verbs as top tabs, black and white only.
08Geist Breadcrumb

Vercel-grade black and white precision: icon rail, breadcrumb header, a flat borderless queue and card-stacked options, very little ornament.
09Explorer Tree

A VS Code-style explorer where verbs are folders, convert groups are subfolders and the options panel reads like a config file.
10Powerline Status

Vim modal energy without the box lines: an airy, borderless workspace where a bold powerline bar at the bottom carries all global state.
11Bottom Dock

Verbs live in a bottom mode dock like a DAW or a camera app, leaving the full height for the queue and options.
12Verb Tint

No sidebar and no side panel: verbs as quiet top tabs, options as one toolbar strip, and each verb owns a whisper of colour on hairlines and progress.
13One Bit

A 1-bit, pixel-precise system: pixel-font headings, dithered progress and nothing but pure white on pure black.
14Serif Contrast

An editorial calm take: a sharp serif title against mono data, spacious rows, almost a printed job sheet in the dark.
15Spreadsheet Grid

The queue is a spreadsheet: column letters, row numbers, cell selection and a formula bar that shows the job as a function.
16Warp Blocks

Each convert group is a command block like Warp terminal: a header command, live output rows, and a block you select as a unit.
17Linear Preview

Preview-first, Linear-style: a narrow keyboard-driven list on the left and a dominant inspector that shows the focused file big, with the group's options beneath.
18Pipeline Board

Status columns instead of a list: queued, running, done and failed lanes with groups as swimlanes, readable at a glance.
19Amber Manpage

Each verb is a man page: one centred document with NAME, SYNOPSIS, OPTIONS and FILES sections, warm paper-white text with amber only on headings and flags.
20HUD Metrics

A status-first HUD: the top third is live metrics with braille sparklines, the queue sits beneath as a quiet list.
